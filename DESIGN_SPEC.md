# CodeTime — терминальный редизайн (TUI)

Спецификация нового дизайна. Единственный источник правды. Код на неё ссылается.

## 0. Зачем

Приложение CodeTime (трекер рабочего времени за VS Code) сейчас выглядит как
обычный SaaS-дашборд: боковое меню с иконками, карточки со скруглениями, вкладки,
плашки. Пользователь попросил **полностью переломать дизайн** — сделать его таким
же, как текстовый терминальный интерфейс (TUI) трекера привычек `init.habits`.

Из приложения **вырезается вся ИИ-часть**: чат с наставником, конвейер агентов
OpenRouter, журнал прогресса, журнал заметок, разбор фото макетов, настройки
OpenRouter / Gemini / GitHub-токена. Остаётся чистый трекер времени.

Итог: приложение выглядит как окно терминала. Моноширинный шрифт, рамки из
символов псевдографики, префиксы `$` у панелей, цвет как в ANSI-палитре,
управление с клавиатуры, строка подсказок снизу.

## 1. Общий вид

```
┌────────────────────────────────────────────────────────────────────────────┐
│ [h] codetime [beta] · обзор · календарь · проекты · план · задачи · 1–6    │
├──────────────────┬───────────────────────────────┬─────────────────────────┤
│ $ статус         │ $ задачи                      │ $ статистика            │
│   вторник, 4 авг │                               │   ◇ за всё время       │
│   серия: 12 дней │   сегодня             [1/3] ▾ │   ♨ серии              │
│   ▓▓▓▓▓░░░  68%   │   [✓] ▸ дописать отчёт   45м │   ⊞ окно данных        │
│   // цель: 60%   │   [ ] ▸ рефакторинг      90м │   ⇶ дневная цель [30д] │
│                  │                               │   ⊞ по дням недели     │
│ $ календарь      │   завтра              [0/2] ▾ │   🏆 итоги             │
│   ‹   август 2026  ›│   [ ] ▸ вёрстка шапки   30м │                         │
│        пн вт ср…  │                               │                         │
│                  │   без срока            [2/1] ▾ │                         │
│ $ вклад          │   [✓] ▸ чтение          20м │                         │
│   янв фев … авг  │                               │                         │
│   ▨▨▨▨▨▨▨▨▨      │   + задача   + группа         │                         │
│   // меньше ░▒▓█  │                               │                         │
├──────────────────┴───────────────────────────────┴─────────────────────────┤
│ ⌥/↓ режим ввода · tab панель вправо · 1–6 меню · a добавить · ? помощь     │
└────────────────────────────────────────────────────────────────────────────┘
```

Три колонки на широком экране. Левая — «сегодня и время», средняя — «что делать»,
правая — «статистика». Это прямое соответствие трём колонкам на референсе
(статус+календарь+вкладки / привычки / статистика).

## 2. Палитра и типографика

Один моноширинный стек на всё приложение. Никаких системных шрифтов.

```css
--font-mono: ui-monospace, 'Cascadia Mono', 'Cascadia Code', 'JetBrains Mono',
             'SF Mono', Consolas, 'DejaVu Sans Mono', 'Liberation Mono',
             'Courier New', monospace;
```

| Токен           | Значение  | Где                                            |
|-----------------|-----------|-----------------------------------------------|
| `--bg`          | `#080a0c` | фон окна                                      |
| `--bg-panel`    | `#0d1114` | фон панели                                    |
| `--bg-raised`   | `#141a1f` | строка-привычка, активная строка              |
| `--bg-inset`    | `#05070a` | поля ввода, «инвертированные» блоки           |
| `--border`      | `#1c262e` | рамка панели                                  |
| `--border-lit`  | `#2b3a46` | рамка активной панели / фокус                 |
| `--fg`          | `#c3d0dc` | основной текст                                |
| `--fg-dim`      | `#5d7080` | приглушённый: подписи, второстепенные строки  |
| `--fg-faint`    | `#394854` | почти невидимый: разделители, выключенное     |
| `--gold`        | `#d8a33c` | префикс `$`, заголовки панелей                |
| `--green`       | `#3fb950` | выполнено, прогресс, хорошие значения        |
| `--amber`       | `#d29922` | серии, внимание, цель                         |
| `--red`         | `#f85149` | опасное, удаление, перерасход                 |
| `--blue`        | `#58a6ff` | ссылки, активный пункт меню                   |
| `--violet`      | `#bc8cff` | проекты, акценты статистики                   |

Правила контраста: `--fg-dim` на `--bg-panel` — не меньше 4.5:1, `--fg-faint` —
используется только для нечитаемого по замыслу декора (рамки, разделители) и
никогда для единственного носителя смысла.

Цвета задаются один раз в `:root` на `[data-theme="light"]`. **Светлая тема
обязательна** — она переключается и должна выглядеть как светлый терминал
(папирусный фон, тёмно-серый текст), а не как инвертированный тёмный.

## 3. Каркас страницы

```
.tui                 — флекс-колонка на всю высоту, padding 10px, gap 8px
  .tui-menu          — верхняя строка меню
  .tui-body          — три колонки, flex:1, min-height:0, gap 8px
    .tui-col         — флекс-колонка, gap 8px, min-height:0
  .tui-footer        — строка подсказок
```

Ширины: `.tui-col--left` 300px, `.tui-col--mid` `1fr`, `.tui-col--right` 340px.

Адаптив:
- ≥1400px — три колонки, как выше.
- 1000–1399px — три колонки сжаты (`260px 1fr 300px`), календарь и вклад
  прячутся (`display:none`) — их данные переносятся в правую панель.
- 720–999px — две колонки: центральная + правая, левая скрыта.
- <720px — одна колонка, панели складываются вертикально, скролл.

Пересчёт при `resize` обязателен: без него таблицы псевдографики «поедут».

## 4. Верхнее меню

Одна строка, вся в моноширике, без кнопок-«пилюль».

```
[h] codetime [beta] · обзор · календарь · проекты · план · задачи · достижения
```

- `[h]` — квадратная рамка вокруг первой буквы названия, костюмный символ.
- `codetime` — обычным текстом; `[beta]` — тусклым.
- Разделитель пунктов — `·` цвета `--fg-faint`.
- Активный пункт — `--fg` + подчёркивание из `_`; остальные `--fg-dim`.
- Пункты — настоящие `<button>`, фокус виден рамкой `--border-lit`.
- Цифры 1–7 в `<kbd>`-подсказках выводятся справа, тусклым. При ширине <1000px
  пункт «достижения» и цифры скрываются, остаётся `меню` со значком `≡`.

Переход по меню переключает `data-screen` у `.tui-body` и активный пункт;
экраны **не** перезагружают данные повторно, если они уже загружены.

## 5. Панель

Панель — не карточка со скруглением. Это рамка в 1px и заголовок **над** рамкой.

```html
<section class="panel" data-panel="status">
  <header class="panel-h">
    <span class="panel-t"><i class="sig">$</i> статус</span>
    <span class="panel-x">×</span>
  </header>
  <div class="panel-b"> … </div>
</section>
```

- `.panel-h` — строка, `padding 0 2px`, высота 20px, цвет `--gold` для `$`
  и `--fg` для названия, `.panel-x` прижата вправо, цвет `--fg-faint`.
- `.panel-b` — `padding 10px 12px`, `border:1px solid var(--border)`,
  `background: var(--bg-panel)`. Скруглений нет нигде.
- `.panel` в фокусе (навигация с клавиатуры) — рамка `--border-lit`,
  и заголовок получает `▌` слева цвета `--blue`.
- Заголовок секции внутри панели — `.sec`:
  `<span class="sec-i">◇</span><span class="sec-t">за всё время</span>`
  плюс справа, при необходимости, метка окна: `за всё время[30д]` —
  `[30д]` тусклым, в квадратных скобках.

## 6. Строки данных

Каждая строка — сетка из трёх колонок, чтобы правый счётчик всегда стоял
по правому краю, а длинный текст обрезался многоточием, а не ломал вёрстку.

```html
<div class="row">
  <span class="row-k">подпись</span>
  <span class="row-dim">пояснение</span>
  <span class="row-v">12.4 ч</span>
</div>
```

`.row-k` — `--fg`; `.row-dim` — `--fg-dim`, курсивом отсутствует; `.row-v` —
`--fg`, `font-variant-numeric: tabular-nums`. Числа во всём приложении
выравниваются по разрядам — обязательно `tabular-nums`, иначе колонки прыгают.

Комментарии-пояснения выводятся строкой ниже, с префиксом `//`, цветом
`--fg-faint`, курсивом. Это часть образа, а не декорация:

```
// цель дня — 6 ч, сейчас 68%
```

## 7. Чекбокс в стиле оболочки

Не квадратная кнопка, а текстовые скобки:

```
[ ] не сделано      [✓] сделано      [·] частично
```

- Реализуется как `<button class="cbx" aria-pressed="true|false">`
  с `::before` = `[✓]` / `[ ]`. Текст `[✓]` — реальный контент в `::before`,
  но для скринридера обязателен `aria-label` и `aria-pressed`.
- Состояния: `[✓]` зелёный `--green`; `[ ]` `--fg-faint`; `[·]` `--amber`.
- Строка с выполненной задачей: текст `--fg-dim` + `text-decoration: line-through`
  цветом `--fg-faint`, счётчик справа гаснет.
- Строка целиком кликабельна (переключает задачу), но ведёт себя как строка
  списка: `cursor:pointer`, при наведении фон `--bg-raised`.
- Минимальная цель нажатия — 28px по высоте и 28px по ширине.

## 8. Полоса прогресса

```
[▓▓▓▓▓▓▓░░░░░░░]  68%
```

- Дорожка — `<div class="bar"><i class="bar-f" style="width:68%"></i></div>`,
  высота 8px, фон `--bg-inset`, без скруглений.
- Заливка — `--green`, при <100% и близко к цели — `--amber`, при перерасходе
  `--red`. Ширина задаётся в процентах, `transition: width .25s`.
- Подпись справа — `tabular-nums`, формат `68% (4ч06м / 6ч)`.
- Тонкая альтернатива для списков — `.bar--thin`, высота 3px, без подписи.

## 9. Календарь месяца

Сетка 7 колонок × 6 строк, понедельник первым.

```
        пн   вт   ср   чт   пт   сб   вс
     ┌────┬────┬────┬────┬────┬────┬────┐
     │ 27 │ 28 │ 29 │ 30 │ 31 │  1 │  2 │
     ├────┼────┼────┼────┼────┼────┼────┤
     │  3 │▓▓ 4│▓▓ 5│  6 │▓▓ 7│  8 │  9 │
```

- Заголовки дней недели — `--fg-faint`, по две буквы, высота строки 18px.
- Ячейка: номер сверху (`--fg`), под ним полоска активности (высота 3px,
  ширина во всю ячейку, цвет по интенсивности активного времени за день).
- Пять уровней интенсивности — тот же ряд цветов, что у вклада (§10).
- Пустые дни (нулевое время) — только номер, `--fg-faint`.
- Дни вне месяца — `--fg-faint`, `aria-hidden`.
- Сегодня — рамка `1px solid var(--blue)`, номер `--fg`.
- Клик по ячейке открывает день: панель-модалку со списком проектов за день.
- Шапка: `‹  август 2026  ›` — кнопки-стрелки, `title` на русском.

## 10. Вклад (тепловая карта года)

Сетка: 7 строк (дни недели, пн первым) × N колонок-недель, сверху вниз по
времени; над колонками — подписи месяцев.

```
          янв   фев   мар   апр   май   июн   июл   авг
    пн   ▨▨▨▨ ▨▨▨▨ ▨▨▨▨ ▨▨▨▨ ▨▨▨▨ ▨▨▨▨ ▨▨▨▨ ▨▨▨▨
    ср   ▨▨▨▨ ▨▨▨▨ ▨▨▨▨ ▨▨▨▨ ▨▨▨▨ ▨▨▨▨ ░░░░ ▨▨▨▨
    пт   ▒▒▒▒ ░░░░ ▒▒▒▒ ▒▒▒▒ ▒▒▒▒ ▒▒▒▒ ▒▒▒▒ ▒▒▒▒
    вс   ░░░░ ░░░░ ░░░░ ░░░░ ░░░░ ░░░░ ░░░░ ░░░░
    // меньше ░ ▒ ▓ █ больше
```

- Ячейка — `▨` для данных, `░` для нулевого дня. Пять ступеней:
  `#0d1114` (нет данных), `rgba(63,185,80,.22)`, `rgba(63,185,80,.42)`,
  `rgba(63,185,80,.68)`, `#3fb950`.
- Порог ступеней — квантили активного времени за окно, а не фиксированные
  минуты: минимум и максимум берутся из данных, делятся на четыре части.
  Так вклад одинаково читается и у новичка, и у того, кто работает по 10 часов.
- Подписи месяцев — `--fg-faint`, ставится только в колонку, где месяц
  реально начинается (иначе подписи наезжают).
- Подпись `// меньше ░ ▒ ▓ █ больше` — внизу панели, `--fg-faint`.

## 11. Бар-чарт по дням недели

Горизонтальные полосы, как в терминале:

```
пн  ▓▓▓▓▓▓▓░░░░░░░░░░░  64%
вт  ▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░  71%
ср  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░  79%
пт  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  88%
// лучший: пт (88%)   худший: вт (41%)
```

- Метка дня — фиксированная колонка шириной 3ch, моношириная.
- Длина полосы 20 символов, `▓` = заполнено, `░` = пусто. Считается в коде
  как `Math.round(pct / 100 * 20)`, при 0% — ноль символов, не один.
- Процент — справа, `tabular-nums`, ширина 5ch.

## 12. Правая панель «статистика»

Секции идут в этом порядке, каждая — `.sec` из §5:

```
$ статистика

◇ за всё время
  // сводка за всё время
  дней с данными      128
  всего активного     1 042.6 ч
  среднее в день      8.1 ч
  лучший день         ср, 14.8 ч

♨ серии
  // подряд достигнутая дневная цель
  текущая серия        12 дней
  рекорд               41 день
  лучший проект        tracker — 12 дней подряд

⊞ окно данных
  // выберите готовый диапазон или свой
  [7д] [30д] [90д] [365д] [всё] [свой…]

⇶ дневная цель [30д]
  // сколько дней цель была закрыта
  цель закрыта          22 / 30
  среднее в будни      6.4 ч
  среднее в выходные   3.1 ч

⊞ по дням недели [30д]
  <бар-чарт из §11>

🏆 итоги [30д]
  // как распределилось время
  ▸ топ-5 проектов
  ▸ языки
```

- Пресеты окна — `<button class="chip">`, активный — `1px solid var(--gold)`,
  текст `--gold`. Нажатие перезапрашивает `/api/overview?days=N`.
- «свой…» открывает модалку с двумя полями дат (без `prompt()` — см. §17).
- Секции сворачиваются по клику на заголовок; состояние — в
  `localStorage['codetime.collapsed']`, переживает перезагрузку.

## 13. Средняя панель — задачи

Это «привычки» на референсе: строки с чекбоксом, названием и счётчиком,
сгруппированные по дату.

```
$ задачи                            [+ задача] [+ группа]

  сегодня                       2 / 3   ▾
  [✓] ▸ дописать отчёт            45м
  [ ] ▸ рефакторинг роутера       90м
  [·] ▸ вычитать главу              —

  завтра                        0 / 2   ▾
  [ ] ▸ вёрстка шапки             30м

  без срока                      1 / 1   ▾
  [✓] ▸ чтение                   20м
```

- Заголовок группы — вся строка кликабельна, сворачивает группу, стрелка `▾`
  становится `▸`. Счётчик `[2/3]` справа от названия, тусклым.
- Иконка-эмодзи задачи (`▸` — заглушка, если эмодзи нет) — заменяет
  разноцветные иконки из старого дизайна; настоящий эмодзи берётся из
  первого символа названия, если это эмодзи-глиф (U+1F300–U+1FAFF).
- Счётчик справа: `45м`, `1ч30м`, `—` если минут нет. Цвет `--fg-dim`.
- Пустая группа не показывается, кроме сегодняшней — там пустота объясняется
  строкой `// задач на сегодня нет`.
- Клик по строке переключает выполнение (`POST /api/todos/toggle`).
- `+ задача` и `+ группа` — обычные кнопки в стиле `.btn-t` (рамка, без
  заливки, текст `--fg`), ведут в модалки из §16.

## 14. Прочие экраны

Те же приёмы, тот же каркас, те же панели. Конкретное наполнение:

- **календарь** — `$ календарь` (месяц, §9) над `$ вклад` (год, §10),
  две панели в левой колонке, справа `$ сводка` с месячными итогами.
- **проекты** — `$ проекты`: строки `.row` с долями, полосами §8 и
  счётчиком дней активности; сортировка кликом по заголовку.
- **план** — `$ цель` (название, дата, часов в день) и `$ шаги`: строки
  шагов со статусом `[✓] / [·] / [ ]`, прогрессом и прогнозом дат.
- **задачи** — полноразмерная версия §13 без группировки по колонкам.
- **достижения** — `$ достижения` с общей полосой `$ счёт` и сеткой плиток;
  плитка — рамка, иконка, название, прогресс; открытые — `--gold`.
- **настройки** — `$ отслеживание` (дневная цель, переключатели), `$ путь`
  (путь к БД), `$ версия` (номер версии, кнопка «список версий»).
  Кнопка **«Установить» обновление не должна работать как раньше** — она
  перезаписывает exe на диске; по умолчанию она заблокирована с подписью
  `нужно подтверждение`.

## 15. Клавиатура

Управление с клавиатуры — обязательная часть образа, а не украшение.

| Клавиши              | Действие                                          |
|----------------------|---------------------------------------------------|
| `1`…`7`              | переход к экрану из верхнего меню                 |
| `←` `→`              | предыдущий / следующий экран                       |
| `Tab` / `Shift+Tab`  | следующая / предыдущая панель в колонке           |
| `↑` `↓`              | строка внутри активной панели                     |
| `Enter` / `Space`    | переключить задачу в фокусе                       |
| `Esc`                | закрыть модалку, снять фокус с панели             |
| `a`                  | новая задача                                      |
| `d`                  | пауза / возобновление отслеживания                |
| `r`                  | перезагрузить данные активного экрана             |
| `?`                  | палитра подсказок (список всех клавиш)            |

Правила:
- Перехват глобальных клавиш не работает, когда фокус в `<input>`,
  `<textarea>` или `<select>`, и когда открыта модалка (там — только `Esc`).
- Активная панель помечена рамкой `--border-lit` и `▌` в заголовке (§5),
  позиция курсора — инвертированным фоном строки `--bg-raised` + `▶` слева.
- Список строк активной панели должен уметь прокручиваться в видимую часть
  (`scrollIntoView({block:'nearest'})`).
- Все сочетания дублируются мышью. Клавиатура — ускорение, а не единственный
  способ.

## 16. Модалки

Тёмная панель с рамкой, заголовок `$ добавить задачу`, поля в одну колонку.

- Открытие/закрытие: `[закрыть]`, `Esc`, клик по затемнению.
- Подтверждения (`удалить`, `сбросить`) — через **собственный** диалог
  приложения с кнопками `удалить` / `отмена`, а не через браузерные
  модалки: см. §17.
- После действия — всплывающее уведомление в правом нижнем углу
  (`.toast`), само исчезает через 3.5 с.

## 17. Жёсткие ограничения

Эти пункты нарушать нельзя, каждый из них уже стоил реального времени.

1. **`window.prompt`, `window.alert`, `window.confirm` в этом приложении не
   существуют.** В собранном EXE они бросают исключение, и код падает молча,
   выглядя при этом рабочим в обычном браузере. Только собственные модалки.
2. **Никаких внешних зависимостей и CDN.** Приложение работает в WebView2
   офлайн. Никаких шрифтов из сети, ни JS-библиотек, ни иконок-спрайтов из
   интернета — только системные шрифты и inline-SVG.
3. **Только `127.0.0.1`.** Приложение слушает локальный порт; любые адреса,
   порты, `python:`/`file:` в ссылках — отклонять.
4. **Никаких `eval`, `innerHTML` с данными пользователя без экранирования.**
   Названия проектов и задач приходят из БД и вставляются через
   `textContent`, а не конкатенацией строк в `innerHTML`.
5. **Весь пользовательский текст на русском.** Комментарии в коде — тоже
   по-русски. Идентификаторы — латиницей.
6. **Совместимость с WebView2** (Chromium ~120): без `dialog`, без
   `showPopover`, без `:has()` в критичных для раскладки правилах, без
   top-level `await`, без модулей (`type="module"` не использовать — файлы
   подключаются обычными `<script>` в глобальную область).
7. **`node --check` должен проходить** для каждого JS-файла.

## 18. Разделение по файлам

Четыре файла, каждый правится ровно одним разработчиком — пересечений нет.

| Файл              | Что внутри                                                        |
|-------------------|-------------------------------------------------------------------|
| `app.css`         | Всё оформление: токены, каркас, панель, строки, бары, вклад, модалки, светлая тема, адаптив. **Без JS.** |
| `tui_widgets.js`  | Примитивы: `TUI.el`, `TUI.text`, `panel`, `row`, `bar`, `cbx`, `chip`, `modal`, `confirm`, `toast`, форматтеры. Загружается **первым**, экспортирует `window.TUIW`. |
| `tui.js`          | Оболочка: реестр экранов, переходы, меню, навигация по панелям, клавиатура, футер, тема, `TUI.api`/`TUI.post`. Загружается вторым, собирает `window.TUI` из `TUIW` и своего состояния. |
| `screens.js`      | Семь экранов: обзор, календарь, проекты, план, задачи, достижения, настройки. Загружается третьим. |

Порядок подключения в `dashboard.html` фиксирован: `tui_widgets.js` → `tui.js` →
`screens.js`. Обычные `<script>`, без `defer` и без модулей.

`dashboard.html` — только каркас: `<link app.css>`, три `<script>` и пустые
контейнеры, которые JS заполняет. Никаких инлайновых стилей и обработчиков
в разметке.

## 19. Контракт между файлами

`tui_widgets.js` экспортирует `window.TUIW` — примитивы и форматтеры.
`tui.js` читает `window.TUIW` и собирает из него `window.TUI`, добавляя
состояние, реестр экранов и навигацию. `screens.js` работает только с `TUI`.

```js
// --- tui_widgets.js -> window.TUIW ---
TUIW.el(tag, props, children)          // создание элемента
TUIW.text(s)                           // текстовый узел
TUIW.frag(children)                    // DocumentFragment
TUIW.panel({ title, actions, body, collapsed })   // панель из §5
TUIW.row({ key, dim, value, hint })    // строка из §6
TUIW.bar(pct, { goal, caption })       // полоса из §8
TUIW.cbx(checked, onToggle, label)     // чекбокс из §7
TUIW.chip(label, active, onClick)      // пресет из §12
TUIW.sec(icon, title, window)          // заголовок секции из §5
TUIW.modal({ title, body, onOk })      // модалка из §16
TUIW.confirm(text, onOk)               // подтверждение (НЕ confirm())
TUIW.toast(text, kind)                 // уведомление
TUIW.closeModal()                      // закрыть верхнюю модалку
TUIW.hmModalOpen()                     // есть ли открытая модалка
TUIW.wbars(items)                       // бар-чарт по дням недели из §11
TUIW.fmt.sec(sec)                      // 1ч30м
TUIW.fmt.hm(sec)                       // 45м
TUIW.fmt.dur(sec)                      // 2д 4ч
TUIW.fmt.clock(sec)                    // 08:40
TUIW.fmt.pct(v)                        // 68%

// --- tui.js -> window.TUI ---
TUI.reg(screenId, { title, load, render, keymap })  // регистрация экрана
TUI.go(screenId)                                    // переход
TUI.refresh()                                       // перезагрузка активного экрана
TUI.onKey(fn)                                       // подписка на клавиши экрана
TUI.state                                           // { screen, settings, data: {} }
TUI.api(path) / TUI.post(path, body)                // обёртки fetch с ошибкой в тост
// плюс всё из TUIW, доступное и как TUI.el, TUI.panel, TUI.fmt и т.д.
```

`load(screenId)` возвращает `Promise` с данными и **кладёт их в `TUI.state.data[screenId]`**.
`render(data, root)` строит DOM внутри `root`. Ошибка загрузки — тост с
русским текстом и пустой, но валидный экран (не белый и не исключение).
