GitHub — доступ к вашему репозиторию с вёрсткой

        
Репозиторий (owner/имя)
          

        
Токен GitHub — Contents: Read + Models: Read (пусто = оставить прежний)
          

        

          Как создать токен (2 минуты, только чтение)
          
    
            
  1. Откройте на GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. 
            
  2. Имя: codetime-mentor, срок: 90 дней.
    3. 
            
  3. Repository access → «Only select repositories» → выберите репозиторий с вёрсткой (приватный подойдёт).
    4. 
            
  4. Permissions → Repository permissions → Contents: Read-only (Metadata включится сам).
    5. 
            
  5. Там же в Account permissions включите Models: Read-only — это право открывает бесплатный ИИ (GitHub Models, gpt-4.1-mini): наставник начнёт видеть фото макетов и уйдут лимиты демо-режима.
    6. 
            
  6. Generate → скопируйте токен github_pat_… → вставьте выше → «Сохранить». Один этот токен даёт и чтение репозитория, и бесплатный ИИ.
    7.
