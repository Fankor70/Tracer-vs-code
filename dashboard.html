        Как получить бесплатный ключ (1 минута)
        
    
          
  1. Заходи на openrouter.ai → Keys и регистрируйся (можно через Google).
    2. 
          
  2. Жми «Create Key», имя любое (например «codetime»), лимиты по умолчанию.
    3. 
          
  3. Скопируй строку sk-or-v1-… сразу — потом её не покажут — и вставь в поле выше.
    4. 
          
  4. Готово. Кредиты не обязательны: бесплатные модели с пометкой free работают без оплаты, лимит — 50 запросов/сутки (после разового пополнения $10 — 1000/сутки).
    5.

Репозиторий (owner/repo)
        

      
Токен (необязательно для публичного репозитория; пусто = оставить прежний)
        

      

        
        
        
      

      

      

        Как создать токен с доступом к репозиторию (2 минуты)
        
    
          
  1. Открой github.com → Settings → Developer settings → Fine-grained tokens.
    2. 
          
  2. Token name: «frontend-mentor», Expiration: 90 дней (потом просто выпусти новый).
    3. 
          
  3. Repository access: «Only select repositories» → отметь репозиторий с учебным проектом.
    4. 
          
  4. Permissions → Repository permissions → Contents: Read-only. Больше ничего не нужно — наставник только читает код. Для бесплатного ИИ через GitHub Models включи там же Account → Models: Read-only.
    5. 
          
  5. «Generate token» → скопируй строку (начинается с github_pat_…) в поле выше.
    6. 
        

        
Если репозиторий публичный — токен можно вообще не указывать, но лимит запросов к GitHub будет ниже (60 в час против 5000).

      

    


    

      
Что знает команда

      

        
— свою роль (наставник и ревьюер, правила разбора кода и макетов) — задана жёстко;

        
— «Журнал прогресса» — долговременная память: папка CodeTimeMentor/journal.md;

        
— текущий план обучения (вкладка «План»);

        
— файлы из подключённого репозитория: структура всегда, содержимое — когда прикрепляешь файлы;

        
— фото макетов: агент «Зрение» описывает картинку и передаёт описание наставнику;

        
— каждый агент — отдельная бесплатная модель OpenRouter; конвейер и связи агентов настраиваются.
